# Algorithms-and-data-structures
Exercises in Algorithms and Data Structures.

The goal of this repository is to practice implementing classic data structures and algorithms, as well as to understand their efficiency and testing methods.
Each folder represents a separate lab or assignment, with source code, tests, and any supplementary files. The documentation for each work is written in Lithuanian.

#### 1 Big Integer
My implementation of the big integer data type using a tied list and numbers stored as 256-bit integers.


## Summary
This repository is intended for learning purposes, showing step-by-step algorithm implementation, testing, and modular project design.
